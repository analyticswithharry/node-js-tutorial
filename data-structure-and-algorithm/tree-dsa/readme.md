## Topics Covered

- **Tree Fundamentals**
  - Nodes, roots, parents, children, and leaves
  - Binary tree construction
  - Tree height, depth, and levels
  - Preorder, inorder, postorder, and level-order traversal
  - Tree properties and recursive algorithms

- **Binary Search Trees**
  - Insertion and searching
  - Node deletion
  - Minimum and maximum values
  - BST validation
  - Predecessor and successor

- **Balanced Trees**
  - AVL trees
  - Red-black trees
  - Tree rotations and rebalancing
  - Logarithmic search, insertion, and deletion

- **Heaps**
  - Min-heaps and max-heaps
  - Insertion and extraction
  - Priority queues
  - Heap sort

- **Tries**
  - Prefix trees
  - Word insertion and searching
  - Prefix matching
  - Autocomplete

- **Range Query Data Structures**
  - Segment trees
  - Lazy propagation
  - Fenwick trees
  - Range queries and efficient updates

- **Multiway Trees**
  - B-trees and B+ trees
  - Node splitting and merging
  - Database indexing concepts

- **Advanced Tree Algorithms**
  - Lowest common ancestor
  - Binary lifting
  - Tree dynamic programming
  - Heavy-light decomposition

## Project Goals

- Understand tree structures from fundamentals to advanced algorithms.
- Implement data structures from scratch.
- Learn how tree operations work internally.
- Analyze time and space complexity.
- Practice DSA problems.
- Explore real-world tree applications.
- Test implementations with edge cases.

## How to Run

Install [Node.js](https://nodejs.org/) if it is not already installed.

Run an individual file:

```bash
node 01-fundamentals/traversals.js
```

Run the test file:

```bash
node tests/tree-tests.js
```
