
# Tree DSA Master

A collection of tree data structures and algorithms implemented in JavaScript.

## Topics

- Tree Fundamentals
- Binary Trees
- Tree Traversals
- Tree Properties
- Binary Search Trees (BST)
- AVL Trees
- Red-Black Trees
- Min-Heaps and Max-Heaps
- Priority Queues
- Heap Sort
- Tries and Prefix Search
- Segment Trees
- Lazy Propagation
- Fenwick Trees
- B-Trees and B+ Trees
- Lowest Common Ancestor (LCA)
- Binary Lifting
- Tree Dynamic Programming
- Heavy-Light Decomposition

## Project Structure

- `01-fundamentals/` — Basic tree concepts and traversals
- `02-binary-search-tree/` — BST operations and validation
- `03-balanced-trees/` — AVL and red-black trees
- `04-heaps/` — Heaps, priority queues, and heap sort
- `05-tries/` — Prefix trees and autocomplete
- `06-range-queries/` — Segment trees and Fenwick trees
- `07-multiway-trees/` — B-trees and B+ trees
- `08-advanced-algorithms/` — Advanced tree algorithms
- `tests/` — Tests for tree implementations

## Technologies

- JavaScript
- Node.js
- Data Structures and Algorithms

## Run

```bash
node 01-fundamentals/traversals.js
```
